# Hi, I'm Reid 👋

Product manager. I build small, real tools for the problems I run into: at work, on the golf course, and in my
fantasy league. Lately that means AI-native workflows: Claude Code skills, agents, and the product judgment
about where AI should and shouldn't sit in a process.

## Featured

**[PM Workbench](https://github.com/reidabook/pm-workbench)** · Python, FastAPI, Claude Code
A local cockpit for product managers: objectives and key results, an evidence-weighted backlog, and a gated
journey from signal → PRD → ready stories in Jira → retro. Fifteen bundled Claude Code skills do the drafting
and reviewing; two quality gates (a PRD gate and a story Definition of Ready) keep vague work out of
engineering. Ships with a demo team and a 17-lesson guided course. `./run.sh --demo` to try it.

**[Fantasy Draft Analytics](https://github.com/reidabook/fantasy-draft-analytics)** · Python, Streamlit
Draft-prep and live-draft assistant for Sleeper and ESPN leagues: value-based drafting rankings, positional
scarcity alerts, a live pick tracker with recommendations, and a sleeper / bust radar.

**[Bush League Bocce](https://github.com/reidabook/bush-bocce-league)** · Next.js · [live](https://bush-league-bocce.vercel.app)
Runs our neighborhood bocce league: standings, weekly sessions with random teams, a seeded tournament
bracket, and an AI assistant the commissioner uses to log results from a phone.

**[Golf Practice](https://github.com/reidabook/golf-practice)** · Next.js, Supabase · [live](https://golf-practice-three.vercel.app)
Mobile-first app for tracking practice-drill scores across training blocks, with progress charts.

**[garmin-swim](https://github.com/reidabook/garmin-swim)** · Python
Write a swim workout in plain text, get it on your Garmin watch: YAML → structured workout → scheduled on
Garmin Connect.

## How I work
- Start from the problem and the evidence, not the feature.
- Make the decision visible: a score anyone can challenge beats a ranking nobody can explain.
- Ship small, measure, and close the loop with a retro.
